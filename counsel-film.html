영화과 입시 — 상 / 중 / 하 그룹별 미션 정리

2026학년도 기준 · 19개교 · 작성 2026-05-05

학교를 학교명이 아니라 "어떤 미션을 시키는가"로 묶어서 봐야 준비 동선이 잡힙니다. 아래는 합격 난이도와 미션 강도로 묶은 상/중/하 그룹과, 학교별로 실제로 시키는 평가 항목입니다.
상위

6개교 · 합격 난이도 최상위

글쓰기 · 영화이해 · 자기 입장 모두 고밀도로 요구. 한 영역만 잘하면 안 되고 종합력이 필요한 그룹.

한예종 영화과

논술 + 구술 + 포트폴리오
  • 1차 논술 (180분): 주어진 주제·소재로 이야기 구성 / 논술 — 독창적 시각 + 논리적 서술력
  • 2차 구술면접: 본인 작품·논술 결과물 기반 심층 질문 / "예술의 사회적 역할" 같은 추상 토픽
  • 포트폴리오 (USB 2개): 작품 + 작품설명서 + 프로필
  • 자기소개서: 성장과정·학창시절·지원동기·노력과정·장래희망

한예종 방송영상과

자체시험 + 면접
  • 영화과와 동일 체계
  • 차이: OTT · 유튜브 등 미디어/방송 환경 견해 비중 ↑
  • 영상 매체에 대한 이해와 시청 경험

중앙대 영화학과

스토리창작 실기 / 학종
  • 스토리창작 실기: 상황 확장 / 중간 연결 / 후속 전개 (단순 서사 완성형 X)
  • 학종 면접: 학생부·자소서 기반 블라인드 면접, 즉흥 창작 질문 가능
  • 경쟁률: 130:1+ · 1~2점 차로 갈리는 고경쟁

한양대 연극영화학과 (영화전공)

면접 · 구술 + 정시 실기
  • 면접·구술: 좋아하는 영화/감독, 본인 예술관, 영화 지식 깊이
  • 정시 실기고사: 길고 고강도 (당일 컨디션 변수 큼)
  • 감독 3명+ 필모그래피 · 연출 스타일 분석 필수

성균관대 영상학과

서류 100% (면접 없음)
  • 탐구형 학종: 서류평가 100%
  • 평가: 학업역량(교과) + 개인역량(비교과) + 잠재역량(성장 가능성)
  • 수능 최저: 국·수·영·탐 2과목 평균 적용

동국대 영화영상학과

서류 → 서류+면접
  • 1단계: 서류 100% (학생부 + 자기소개서)
  • 2단계: 서류 70% + 면접 30%
  • 면접: 서류 기반 심층질의 (제시문 없음), 독서·교과·진로 관련
중위

7개교 · 메인 카드 후보군

글쓰기 / 면접 중 한 영역이 강하면 합격권. 수시 6장에서 중심 라인업으로 짜기 좋은 그룹.

세종대 영화예술학과 (연출제작)

3시간 작문 + 5분 발표
  • 1단계: 스토리 구성 실기 100% (3시간, 제시 단어/상황 활용) → 6배수 선발
  • 2단계: 발표 5분 + 학생부 + 1단계 성적 종합
  • 포인트: 시간 배분 + 발표 프레젠테이션 능력

건국대 영화학과

학종 면접 10분
  • 학종 면접: 10분, 위원 2~3명 vs 1명
  • 평가축: 전공적합성 + 인성(소통) + 발전가능성(종합 사고력)
  • ※ 건국대 영상학과는 별도 — 기초디자인 실기 (미술 트랙)

서울예대 영화과 (전문대)

작문 + 이미지 분석 + 구두문답
  • 1차 작문 (50분): 제시어 3~5개 포함, 한 문장 3줄 이하 · 전체 12문장 이내 줄거리
  • 1차 이미지 분석 (10분): 한 장의 이미지 미학적 분석
  • 2차: 이미지 분석 + 구두문답

단국대 죽전 영화콘텐츠전공

실기 + 면접 (영화 토론형)
  • 면접: 준비 20분 / 답변 6분 (예능계)
  • 성격: 영화 토론형 — 영화 지식 · 견해 평가
  • 입학처 공개 기출문제 + 모의 토론 연습

명지대 영화학과

학종 심층면접 10분
  • 심층면접: 10분, 위원 2명 vs 1명
  • 기반: 학생부 (반복 기록된 전공 활동, 리더십, 자기주도성)
  • 입학처 "수시-기출자료"에 면접 예시문항 공개

상명대 영화전공 (영화·뮤지컬)

정보 부족 · 입학처 확인
  • 영화·뮤지컬 복합 전공 특성 이해 필요
  • 논술 기출은 공개되지만 영화전공 실기 기출은 별도 확인
  • 입학처 직접 문의 권장

서경대 영화영상학과

실기우수자 · 컷오프
  • 전형: 교과 + 실기고사 합산
  • 컷오프: 실기고사 기준점수 미달 시 무조건 탈락 (모집인원 무관)
  • 입학처에 실기 형식·내용 직접 문의 권장
하위

6개교 · 안정 카드

면접·인성 위주가 많아 글쓰기 베이스 살리기 좋음. 청주대만 영화이론(교차편집·시나리오 3요소) 추가 필요.

단국대 천안 공연영화학부 영화전공

실기우수자 · 이론/연출/스탭
  • 실기우수자 전형 (이론·연출·스탭 세부)
  • 정시 이월 시 수능 100% 선발
  • 본인의 세부 전공 방향 명확화 필요

청주대 영화학과

장면구성 + 이론 + 면접
  • 이론 출제: 교차편집 · 시나리오 3요소 · 몽타주
  • 장면구성: 약 25분 사고 시간 부여
  • 면접: 만들고 싶은 영화 장르·이유, 현장 인간관계 경험

수원대 영화영상학과

인성면접 · ZOOM 화상
  • 면접: 1분 자기소개 + 구술 (블라인드)
  • 출제 경향: "어떤 꿈을 가졌는가", 미디어 환경 견해, 사회 이슈
  • 인재상(큰 꿈 · 창의성 · 실행력) 숙지

추계예술대 영화학과

작문 + 면접 (추정)
  • 정시: 실기 60% + 수능 40% (문창과 기준, 영화 별도 확인)
  • 저내신·검정고시도 실기로 합격 사례 있음
  • 입학처 직접 문의 권장

백석예술대 영상학부 영화콘텐츠전공

실기(작문) + 면접
  • 비중: 실기 70% + 학생부 30%
  • 면접 출제 예: "AI가 영화산업에 도입되는 것에 대한 의견" — 시사 비중↑

대진대 영화방송학과

면접형 (학생부 기반)
  • 평가: 논리적 사고력 + 창의능력
  • 입학처에 인문/자연 계열별 면접 문항 3개씩 공개
  • 공개 문항 모의 답변 + 영화·방송 기본 이해
