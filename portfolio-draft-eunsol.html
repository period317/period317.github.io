대표님 경험 기반 확신은 강했지만,
실제 사용자 데이터가 전혀 없었다.
"우리가 만들면 성공한다"가 유일한 근거.

02 / 09
01 · 리서치 3단계

납득할 수 있는 근거를
직접 찾아다녔다

STEP 1

오픈채팅방 전수 조사

분양상담사 카카오 오픈채팅방에 직접 입장 → "문자" 키워드 전수 조사.
발견: 언급의 80%가 스팸·과태료 이야기.
전환: "예쁜 UI" → "스팸 예방 환경 설계"로 기능 방향 재설정.

STEP 2

법률 검토 직접 수행

사내 법무 없음 → 로톡으로 변호사 직접 컨택.
7주간 매일 변호사 2명씩 컨택. 기준: 유사 해결 사례 보유 여부.
15분 상담 전 1,000자 폼 작성 + 상담 직후 법률검토의뢰서 전달하는 프로세스 자체 설계.
4회 상담 만에 최종 계약 체결.

STEP 3

현장 출장 인터뷰

직급별 구성 가설 수립: 본부장(전체 관리) · 팀장(현장 영업) · 아이스브레이킹 1인.
현장에서 보수적 답변 반복 → "스팸 규제 흐름 먼저 공유 후 가르쳐달라"로 전환.
결과: 결제 사이클·문자 작성 방식 인사이트 → 기능 우선순위 재설계.

애초에 신고 당하지 않고 고객에게 제대로 닿는 예방책이어야 한다.

02 · 기능 설계

5대 스팸진단 기술

1
스팸 점수화
시스템
실시간
작성 중 0~100점 실시간 산출. 안전·주의·위험 구간 시각화. 90점 미만이면 발송 버튼 자체 비활성화. 통신사 필터링 기준 + 수신자 신고 패턴 + 과거 발송 데이터 종합.
2
클린 템플릿
자동 전환
전환 유도
버튼 하나로 발송 성공률 검증된 양식으로 즉시 변환. 변환 전후 스팸 점수 비교 노출. 무료 제공으로 성공 경험 → 유료 대량발송 전환 유도.
3
스팸 필터링
우선 발송
보호
주소록에서 주 3회 이상 수신자 자동 제외 후 우선 발송. 발송 시 "정말 보내시겠습니까?" 팝업으로 판단 책임을 사용자에게 명확히 이전 → 법적 리스크 분산.
4
전용 템플릿
라이브러리
도메인 특화
출장 인터뷰 인사이트 기반. 모델하우스 오픈·청약·계약·입주 등 시나리오별 완성형 문장 제공. 기존 서비스(명절·축하 카테고리)와 달리 분양 실무에서 바로 쓰는 양식.
5
3사 테스트
발송
안심
본 발송 전 SKT·KT·LGU+ 수신 상태 + 스팸 처리 여부 사전 확인. 3회까지 무료, 이후 포인트 차감 → 남용 방지 + 진입 장벽 최소화. 현장에서 발견한 "이유 모를 발송 실패" 문제에서 착안.
